# Local Blender and MakeHuman assets

This directory intentionally excludes downloaded archives and expanded
third-party assets from Git. That keeps the public repository small and avoids
redistributing files without a recorded source and license.

## Pants 01

1. Download the MakeHuman **Pants 01** CC0 asset pack from
   <https://static.makehumancommunity.org/assets/assetpacks/pants01.html>.
2. Store the archive locally as `blender/assets/pants01_cc0.zip` if desired.
3. Extract it to `blender/assets/pants01_cc0/`.
4. Confirm this path exists before rebuilding scenes that use the jeans shorts:
   `blender/assets/pants01_cc0/clothes/cortu_jeans_shorts/`.

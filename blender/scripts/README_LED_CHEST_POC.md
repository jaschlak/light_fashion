# Cyan LED Chest Proof of Concept

> **Modeling note:** this scene currently models a XIAO-sized controller, ten
> pixels at 30 pixels/m, and a 420 mAh battery. The current physical bench test
> instead uses a HUZZAH32, 18 pixels at 60 pixels/m, and USB power. See
> `docs/HARDWARE.md` and `docs/BENCH_TEST.md`; do not treat the Blender scene as
> the electrical wiring specification.

This project is generated by `build_led_chest_poc.py` from the existing
`led_outfit_vest_v001.blend` avatar scene. The script preserves the avatar,
rig, and shirt, then replaces only collections whose names begin with `POC_`.
It is safe to rerun while iterating on the proof of concept.

## Generated design

- Flush sheer-fabric light window over 10 addressable pixels (30 pixels/m)
- Removable internal flex carrier with three soft sew-on attachment tabs
- Three-conductor cable concealed inside the right side seam
- Bare conformal-coated 21 x 17.8 mm XIAO ESP32-C3 stitched flat to an
  internal removable textile carrier
- 330 ohm data resistor and low-profile 680 uF input capacitor
- Protected 3.7 V / 420 mAh flat LiPo, about 55 x 35 x 3.5 mm, in a separate
  removable fabric sleeve
- 500 mA resettable PTC, internal battery disconnect, common ground, and
  flexible 24 AWG power conductors
- No external electronics belt, light tube, channel, connector, switch, cable,
  enclosure, or rigid component in the armpit
- Tailored CC0 denim shorts using Cortu's real MakeHuman garment mesh. The
  waistband is fitted inward independently from the hip/leg allowance, so the
  garment reads as ordinary clothing rather than a hardware enclosure
- All electronics remain at the rear side hem, never over the groin

The shorts come from the official MakeHuman **Pants 01** CC0 asset pack:
`blender/assets/pants01_cc0/clothes/cortu_jeans_shorts`. Source and license:
<https://static.makehumancommunity.org/assets/assetpacks/pants01.html>.

The Blender scene also contains a `LED_CHEST_POC_README` text block and custom
properties on the modeled components so the electrical assumptions travel with
the `.blend` file.

## Run from PowerShell

From the project root:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' `
  --background `
  --factory-startup `
  'D:\Development\openai_projects\wears\Light_Fashion\blender\scenes\led_outfit_vest_v001.blend' `
  --python 'D:\Development\openai_projects\wears\Light_Fashion\blender\scripts\build_led_chest_poc.py'
```

If Blender is installed somewhere else, change only the first quoted path.

## Run inside Blender

1. Open `blender/scenes/led_outfit_vest_v001.blend`.
2. Open the **Scripting** workspace.
3. Open `blender/scripts/build_led_chest_poc.py` in the Text Editor.
4. Click **Run Script**.

## Electrical starting point

The script assumes a 40% brightness cap and an initial WLED current limit of
350 mA. Ten pixels draw roughly 0.40 A at maximum cyan, plus controller
overhead; normal animated use at the brightness cap is estimated around
0.20–0.30 A total. A 420 mAh battery should provide roughly 1–2 hours in this
usage range. This capacity is intentionally traded for a 3.5 mm battery profile.
These are design estimates, not a substitute for measuring the built garment.

Bench-test the complete assembly before wearing it. Verify that the chosen
pixel strip behaves correctly across the protected LiPo's voltage range,
measure current and enclosure temperature, provide strain relief at every
connector, and keep rigid parts off pressure points. Remove the battery before
charging and remove all electronics before washing. Use only a protected LiPo
with a PCM from a reputable supplier; do not charge or wear it while wet.

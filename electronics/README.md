# Electronics

This directory is reserved for the KiCad source-of-truth project.

Planned deliverables:

- Electrical schematic with real component and connector pin numbers
- Dimensionally accurate PCB/interconnect layout
- Board 3D view and mechanical dimensions
- Bill of materials with manufacturer part numbers
- Verified battery, protection, switch, and connector specifications
- Assembly drawing that distinguishes the garment wiring harness from PCB
  traces

Generated Gerbers, fabrication packages, and local KiCad backup files are
ignored. Editable `.kicad_pro`, `.kicad_sch`, and `.kicad_pcb` sources should
be committed.

Until that design exists, use [the documented HUZZAH32 bench circuit](../docs/BENCH_TEST.md).
